# Snap & Study

Snap & Study is an AI-powered study assistant that helps students understand study material using images and text.

## Features

- Upload a photo of a question, textbook page, diagram, or handwritten notes
- Ask study-related questions using text
- Get simple explanations using Gemini AI
- Identify important concepts and revision points
- Send the study summary to Gmail

## Technology Used

- Python
- Streamlit
- Google Gemini API
- Gmail SMTP
